# Lista de Tarefas

Script simples em Bash para gerenciar uma lista de tarefas em um arquivo de texto.

## Como usar

```bash
chmod +x tarefas.sh
./tarefas.sh
```

Para adicionar uma tarefa:
```bash
echo "Nova tarefa" >> tarefas.txt
```

Para buscar uma tarefa:
```bash
grep "palavra-chave" tarefas.txt
```
